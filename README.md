# Ali Raza — AI Portfolio

A chat-style personal portfolio, in the style of a single-page portfolio that talks back. Built with plain HTML, CSS and JavaScript — no API key, no build step.

Open `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/

## Sections

- **Me** — who Ali Raza is, BS AI (2024), Lahore, Pakistan, open to work
- **Projects** — 8 projects with filters: DocuChat, Roman Urdu Assistant, ShopBot, Campus Study Assistant, SupportPilot, CodePilot, ChatWave, pk-validators, each linking to its GitHub repo
- **Skills** — Python, JavaScript, HTML, CSS, AI chatbots, GitHub, VS Code, Node testing
- **Agent Demo** — a local demo of the SupportPilot-style support assistant idea
- **Contact** — GitHub only for now; email/WhatsApp can be added when shared

## Honest notes

- The chat answers are keyword-matched locally, not a cloud LLM.
- CodePilot and the other assistants are pattern/template based, as noted in their own READMEs.
