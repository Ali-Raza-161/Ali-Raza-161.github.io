# Ali Raza — AI Portfolio

A chat-style personal portfolio, in the style of a single-page portfolio that talks back. Built with plain HTML, CSS and JavaScript — no API key, no build step.

Open `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/

## Sections

- **Me** — who Ali Raza is, BSAI from UMT Lahore (2024), Lahore, Pakistan, open to work
- **Projects** — 8 projects with filters: DocuChat, Roman Urdu Assistant, ShopBot, Campus Study Assistant, SupportPilot, CodePilot, ChatWave, pk-validators, each linking to its GitHub repo
- **Skills** — project-based: Python, JavaScript, HTML5, CSS3; intent matching, Roman Urdu NLP, document Q&A with citations, prompt-to-code, support chatbots, explain/bug/refactor; responsive UI, dashboards, chat UI, localStorage, embed widgets; regex/formatting, CNIC/NTN/mobile/IBAN MOD-97 validation, cart/order and quiz/planner logic; GitHub/Pages, VS Code, Node and Playwright testing
- **Agent Demo** — a local demo of the SupportPilot-style support assistant idea
- **Contact** — phone, email and GitHub, as shared by Ali Raza
- **Cursor colour effect** — soft colourful orbs follow the mouse and fade away, plus hover colour on project cards and topic buttons
